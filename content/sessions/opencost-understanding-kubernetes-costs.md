Managers ask many questions, but engineers can answer only a few. When it comes to costs, they can't answer any.

Cloud costs, especially in the world of Kubernetes is complicated to measure. Most deployed artifacts in Kubernetes are ephemeral. Most constructs are virtual. This complicates tracking and measuring costs complex.

There is always a cloud bill. But it does not have any of the details.

In this talk, let's look at OpenCost - a CNCF project - built to solve this exact problem. It will allow you to monitor costs of pods, namespaces, and other entities by default. It uses a combination of Prometheus and cloud APIs to provide the most accurate cost estimates.

The talk will contain details about the tool and will include a comprehensive demo of how it will work.

Bonus: OpenCost now has an MCP server which can be used to learn about costs using AI agents.
