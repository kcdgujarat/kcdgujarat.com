Large Language Models are rapidly becoming part of enterprise platforms, but they introduce entirely new attack surfaces—from prompt injection and insecure tool usage to excessive agency and sensitive data leakage. The OWASP Top 10 for LLM Applications provides a practical framework for understanding these risks.

In this session, we'll explore how Kubernetes can be used as a security platform for AI workloads. Rather than focusing only on model security, we'll demonstrate how cloud-native technologies such as Network Policies, RBAC, service meshes, admission controllers, secrets management, runtime security, and observability can significantly reduce the attack surface of LLM-powered applications.

Through practical architecture patterns and demonstrations, attendees will learn how to build secure, scalable, and production-ready AI platforms on Kubernetes.
